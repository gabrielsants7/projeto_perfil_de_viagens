# 🌍 Projeto Perfil de Viagens

Uma página web desenvolvida com HTML e CSS que simula um perfil pessoal de viagens, exibindo informações do usuário e uma galeria de fotos dos lugares visitados.

🔗 **Acesse o projeto online:**  
https://gabrielsants7.github.io/projeto_perfil_de_viagens/

---

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com foco em:

- Estruturação semântica com HTML5  
- Organização modular de estilos com CSS  
- Uso de variáveis CSS para padronização visual  
- Layout com Flexbox  
- Separação de responsabilidades nos arquivos de estilo  

A proposta é apresentar um perfil pessoal no estilo rede social, destacando bio, informações e galeria de imagens.

---

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3  
- Flexbox  
- Google Fonts (Poppins)

---

## 🎯 Funcionalidades

- ✅ Navbar estruturada  
- ✅ Header com perfil e informações  
- ✅ Galeria de imagens com Flexbox  
- ✅ Footer com informações adicionais

## 🚀 Como Executar Localmente

1. Clone o repositório:

```
git clone https://github.com/gabrielsants7/projeto_perfil_de_viagens.git
```

2. Acesse a pasta do projeto:

```
cd projeto_perfil_de_viagens
```

3. Abra o arquivo `index.html` no navegador.

---

## 🎨 Organização dos Estilos

O projeto utiliza:

- `global.css` → variáveis, reset e estilos globais  
- `index.css` → arquivo central que importa os demais estilos  
- Arquivos separados para cada seção da página (nav, header, main e footer)
